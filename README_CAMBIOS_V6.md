# ANCLO Plásticos · V6

- Plano operativo editable: botón **Editar planta**, arrastrar/reordenar máquinas entre lado izquierdo, derecho e inferior; distribución persistida localmente.
- Tarjetas enriquecidas: producto/OP, avance, producido/solicitado, faltante, ciclo teórico, último ciclo real, desviación %, personal registrado, cola y semáforo de cumplimiento cuando existe fin planeado.
- No se inventan ciclos ni retrasos: si Planeación/Producción aún no tiene el dato, se muestra pendiente/—.
- Catálogo Personal precargado con los 29 registros entregados, editable y persistente localmente.
- Se conserva Planeación semanal, Producción diaria, Historial, Concentrado, Reportes, Máquinas y demás módulos de V5.

Nota: esta versión sigue sin requerir SQL nuevo; es para validar flujo/interfaz antes de persistencia completa en Supabase.
