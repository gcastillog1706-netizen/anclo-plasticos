# ANCLO Plásticos V9.8

- Planeación por programa semanal/quincenal.
- Folio ANCLO automático para toda orden, con OP oficial opcional.
- Captura rápida: OP, producto/clave, piezas y fecha; folio automático.
- Tarjetas de OP retraíbles; órdenes ya capturadas inician contraídas y nuevas/incompletas abiertas.
- Material/lotes retraíbles y ligados una sola vez a la OP.
- Partidas múltiples por OP: Producto/Clave → No. molde → descripción → cavidades → máquina.
- Ciclo, pz/ciclo y capacidad se cargan desde el maestro técnico.
- Gantt calcula horas, inicio y fin estimados por capacidad y cola de máquina (estimación continua 24 h provisional hasta definir calendario real de turnos).
- Monitoreo lee las partidas reales de Planeación y muestra Programada/Produciendo, Folio, OP, producto, molde, cavidades, avance y fin estimado.
- KPIs leen únicamente programa, órdenes, partidas y producción real; sin números demo.
- Concentrado/Producción permanecen ligados al mismo almacén operativo compartido.
