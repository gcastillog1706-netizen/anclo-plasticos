# V10.5 · Calidad + Tensión integradas

- Vercel conserva las claves maestras de producto.
- Regla de destino para cinchos: clave terminada en `PRO` = SUCURSAL; clave terminada en `PRO A` = HOME DEPOT.
- Estudios de tensión recuperan especificaciones dimensionales/fuerza de Streamlit para familias 100/140/180/200/300/370.
- Plan de muestreo Streamlit J/K/L/M/N: 80/125/200/315/500 muestras, con Ac/Re y bolsas.
- Carga rápida desde Producción: producto, máquina, molde, cavidades, cantidad y operadores.
- Personal faltante puede cargarse al iniciar el estudio o al liberar Calidad.
- Captura rápida de fuerza; cavidad se solicita solamente cuando NO CUMPLE.
- Estudios incompletos quedan EN CAPTURA y se pueden continuar.
- PDF de estudio descargable e historial.
- Persistencia sigue protegida por `app_persistencia` en el mismo Supabase de Vercel.
- No se incluye ningún DROP/TRUNCATE/DELETE de datos operativos.
