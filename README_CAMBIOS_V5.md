# ANCLO Plásticos – V5

- Nuevo catálogo **Máquinas** con las 20 máquinas actuales, edición, alta, duplicado, baja/fuera de servicio y eliminación controlada en esta fase local.
- **Producción diaria** organizada por Semana → Lunes a Viernes → Turno Día/Noche.
- Producción toma automáticamente las partidas guardadas en Planeación de la misma semana.
- Captura masiva por tabla: operadores, resultado, kg, piezas, ciclo real, cavidades reales, merma, purga, horas y observación/motivo.
- Acumulado y faltante se calculan por partida semanal.
- Se conserva el flujo de Planeación V4: Material/Programa → Programación rápida → Gantt preliminar.
- Máquinas se agrega al menú junto a Moldes/Herramientas y Personal.

## Importante
Esta versión sigue usando almacenamiento local para validar el flujo visual. No ejecutar SQL nuevo en Supabase todavía.
