# V9.5 – Programa, OP, material y datos reales

- Planeación deja de estar limitada a una semana: crea programas SEMANALES o QUINCENALES con fecha recibida, inicio y fin.
- La OP es la entidad principal: producto, piezas solicitadas y fecha compromiso.
- El material liberado (virgen, reciclado y pigmento con lotes) se registra una sola vez por OP.
- Una OP puede dividirse en múltiples partidas Molde + Máquina + cantidad asignada + semana.
- La capacidad de cada partida usa el estándar exacto Producto + Molde + Máquina.
- Producción Día/Noche lee únicamente partidas reales de Planeación.
- Concentrado diario elimina datos demo y se calcula únicamente con producción registrada.
- Moldes/Herramientas agrega Eliminar por registro de proceso con confirmación.
