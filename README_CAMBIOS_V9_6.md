# V9.6 — Folio interno ANCLO para producción sin OP

- Toda orden recibe automáticamente un folio `INT-AAAA-0001`.
- Se distingue `OP oficial` de `Sin OP / Interna`.
- Una orden interna puede recibir posteriormente una OP oficial sin crear otro registro ni perder producción/material/historial.
- Motivos sin OP: Stock, Prueba, Reposición, Muestra, Reproceso u Otro.
- Folio interno visible en Planeación, Programación, Producción Día/Noche y Concentrado diario.
- Material continúa liberándose a nivel de orden/folio, nunca por máquina.
- Las partidas siguen permitiendo repartir una orden entre varios moldes y máquinas.
